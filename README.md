# CS4207 Coding Challenge – Group 11: next-hour NYC taxi demand, sequential vs parallel

**Group 11:** Saif Khawaldeh, Samuel Luke, Simon Alexander, Iwan Teague, Kevin Monahan

Forecast the number of NYC yellow-taxi pickups in the next hour from the TLC trip records
(Jan 2024 – Sep 2026, 33 monthly Parquet files, ~123.5 M trips). The cleaning pipeline uses **data
parallelism** (one process per month file); feature extraction and the hyperparameter search use **task
parallelism**. Every parallel result is verified identical to the sequential one and benchmarked.

## Files

| Path | What |
|---|---|
| `demand_forecast.ipynb` | **The submission notebook** (executed, with outputs). Generated from `demand_forecast.py` (jupytext). |
| `src/demand/` | Functions used by the notebook and its worker processes: `config.py` (all settings), `io.py`, `cleaning.py`, `parallel.py`, `features.py`, `models.py`, `nondeterminism.py`, `plotting.py` |
| `scripts/benchmark.py` | Timing benchmarks (warm-up + 3 repeats, 1/2/4/8 workers) → `outputs/benchmarks.csv` |
| `scripts/make_poster.py` | Builds `poster/poster.pptx` from `outputs/results.json` and `figures/` |
| `scripts/compare_results.py` | Checks two notebook runs give the same results (apart from timings) |
| `outputs/` | `results.json` (source of every poster number), cleaning table, metrics, benchmarks, non-determinism evidence |
| `figures/` | All figures (300 dpi), generated by the notebook |
| `docs/` | `EXPLAINER.md`, `QA_PREP.md`, `PRESENTATION_SCRIPT.md`, `AI_USE.md` |

## How to run (on Rockhill)

```bash
cd ~/cs4207-group11-demand
python3 -m venv ~/venv && source ~/venv/bin/activate && pip install -r requirements.txt
sbatch run_benchmark.slurm      # optional, ~50 min: refreshes outputs/benchmarks.csv
sbatch run_notebook.slurm       # executes demand_forecast.ipynb in place (~7 min, 8 CPUs, 32 GB)
python scripts/make_poster.py && soffice --headless --convert-to pdf --outdir poster poster/poster.pptx
```

Both Slurm scripts use partition `cs4207`, request memory and time explicitly, and no GPU.
